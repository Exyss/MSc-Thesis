\section{Propositional logic}

Propositional logic serves as the foundational mathematical framework for reasoning over declarative statements using boolean truth values and formal logical operators. For our purposes, we'll be interested in a fragment of propositional logic that works with finite amount of elements.

Let $\mathcal{P} = \{x_1, \ldots, x_n\}$ denote a non-empty, finite set of atomic propositional symbols, called \textit{variables}. Let $\Omega = \{\land, \lor, \lnot, \to, \leftrightarrow\}$ be a set of logical connectives. Each of these constructors represents, respectively, the concept of conjunction, disjunction, negation, implication and logical equivalence.

The set of formulas $\mathrm{Fml}(\mathcal{P})$ generated by $\mathcal{P}$ is the free algebra generated by $\mathcal{P}$. Inductively, $\mathrm{Fml}(\mathcal{P})$ is the smallest set satisfying the following three conditions:
\begin{itemize}
   \item $\mathcal{P} \subset \mathrm{Fml}(\mathcal{P})$;
   \item If $\varphi \in \mathrm{Fml}(\mathcal{P})$ then $\neg \varphi \in \mathrm{Fml}(\mathcal{P})$;
   \item If $\varphi, \psi \in \mathrm{Fml}(\mathcal{P})$ and $\circ \in \Omega$ then $(\varphi \circ \psi) \in \mathrm{Fml}(\mathcal{P})$.
\end{itemize}

The set $\mathrm{Fml}(\mathcal{P})$ defines propositional logic from a syntactical point of view, i.e. how correct formulas are written. To give meaning to the formulas, we have to also define it from a semantical prospective. An \textit{assignment} is a mapping $\alpha : \mathcal{P} \to \{0,1\}$ that sets a truth value to each variable. By extension, each assignment $\alpha$ over variables induces an assignment $\widehat{\alpha} : \mathrm{Fml}(\mathcal{P}) \to \{0,1\}$ through the semantical meaning of the logical connectives:
\begin{itemize}
  \item $\widehat{\alpha}(\lnot \varphi) = 1$ if and only if $\widehat{\alpha}(\varphi) = 0$
  \item $\widehat{\alpha}(\varphi \land \psi) = 1$ if and only if $\widehat{\alpha}(\varphi) = \widehat{\alpha}(\psi) = 1$
  \item $\widehat{\alpha}(\varphi \lor \psi) = 0$ if and only if $\widehat{\alpha}(\varphi) = \widehat{\alpha}(\psi) = 0$
  \item $\widehat{\alpha}(\varphi \to \psi) = 1$ if and only if $\widehat{\alpha}(\psi) = 1$ whenever $\widehat{\alpha}(\varphi) = 1$ holds
  \item $\widehat{\alpha}(\varphi \leftrightarrow \psi) = 1$ if and only if $\widehat{\alpha}(\varphi \to \psi) = \widehat{\alpha}(\psi \to \varphi) = 1$
\end{itemize}

By recursively combining these constructs, we can build more complex formulas that fully express a sentence. For instance, the sentence \curlyquotes{I'll take my umbrella and my boots if it rains} can be modeled by the formula $R \to (U \land B)$. A formula $\varphi \in \mathrm{Fml}(\mathcal{P})$ is said to be \textit{satisfiable} if there is at least one assignment $\alpha$ such that $\alpha(\varphi) = 1$. When all possible assignments satisfy a formula, we refer to that formula as a \textit{tautology}, or simply as true formulas. Clearly, $\varphi$ is a tautology if and only if $\lnot \varphi$ is unsatisfiable.

Given a Boolean variable $x$, a \textit{literal} $\ell$ of $x$ is either the variable $x_i$ itself or its negation $\lnot x$. A \textit{clause} is a disjunction of literals, $C = \ell_1 \lor \ldots \lor \ell_k$, while a \textit{term} is a conjunction of them, $T = \ell_1 \land \ldots \land \ell_t$. A \textit{conjunctive normal form} (CNF) formula $\varphi$ is a conjunction of $m$ clauses $C_1, \ldots, C_m$. Similarly, a \textit{disjunctive normal form} (DNF) formula is a disjunction of $s$ terms $T_1, \ldots, T_s$. Any formula can be written as an equivalent CNF or an equivalent DNF. For instance, the formula $\varphi = ((x_1 \lor \lnot x_2) \land x_3) \lor x_4$ can be written as the CNF formula $(x_1 \lor \lnot x_2 \lor x_4) \land (x_3 \lor x_4)$ or as the DNF formula $(x_1 \land x_3) \lor (\lnot x_2 \land x_3) \lor x_4$.

Depending on the objective, a problem can ask for a binary answer, a specific solution structure or the best possible solution out of many. We divide these problems into three categories: \textit{decision}, \textit{search} and \textit{optimization}. A decision problem is a problem for which we're asked to determine if a chosen property holds for a given an instance of the problem. A search problem, instead, asks to find some structure that certifies the validity of the chosen property. Similarly, an optimization problem asks us to find the optimal structure among all the available ones. It's easy to see that these three ideas form some sort of hierarchy between types of problems. In general, optimization problems are harder than search problems, which in turn are harder than decision problems.

We face these types of problems every day in our life. For instance, suppose that we want to reach a destination $B$ from a starting point $A$. If we're interested in finding the \textit{shortest} route between point $A$ and $B$, this becomes an optimization problem. If we want find any kind of route between the two sites, without caring about its length, this becomes a search problem. If, instead, we want to just establish the existence of at least one route, this becomes a decision problem.  

Let $\Sigma$ be a finite set of symbols (e.g. $\Sigma = \{a,b,c, 0, \$, 3, x, \ldots\}$), referred to as \textit{alphabet}, and let $\Sigma^*$ be the infinite set of all finite strings formed by characters taken from that alphabet. Any subset $L \subseteq \Sigma^*$ is referred to as a \textit{language}. Typically, we're interested to the case where $\Sigma = \{0,1\}$.

Consider a binary predicate $P : \Sigma^* \to \{0,1\}$ representing some property, meaning that $P(x) = 1$ means that the property holds for the input instance $x$ and $P(x) = 0$ means that it doesn't. Let $R_P \subseteq \Sigma^* \times \Sigma^*$ be the binary relation such that $R_P(x,y)$ holds if and only if $y$ certifies the fact that $P(x) = 1$. We refer to $\mathrm{Sol}_P(x) = \{y \in \Sigma^* \mid R_P(x,y)\}$ as the set of \textit{solutions} (or \textit{witnesses}) for the instance $x$ over the property $P$.

\begin{definition}
  The decision problem of $P$ is defined as the language $\Pi_{\text{dec}}^P = \{x \in \Sigma^* \mid \mathrm{Sol}_P(x) \neq \varnothing\}$. The problem $\Pi_{\text{dec}}^P$ is said to be computable if there is an algorithm $\mathcal{A}$ such that $\mathcal{A}(x) = 1$ when $\mathrm{Sol}_P(x) \neq \varnothing$ and $\mathcal{A}(x) = 0$ otherwise.
\end{definition}

We observe that the above definition of computability for decision problem can also be stated as the existence of an always-halting algorithm $L(\mathcal{A}) =\Pi_{\text{dec}}^P$. Moreover, we also observe that the above definition could've been stated without the use of the binary relationship $R_P$ since $\Pi_{\text{dec}}^P = \{x \in \Sigma^* \mid P(x) = 1\}$ is an equivalent definition. In this setting, the definition is given using $R_P$ only for consistency with search and optimization problems. In fact, for the other two types of problems binary relationships are necessary due to the fact that one instance may have more than one possible witness. For instance, there may be more than one (optimal) route from point $A$ to point $B$.

\begin{definition}
  The search problem of $P$ is defined as the binary relationship $\Pi_{\text{search}}^P = R_P$. The problem $\Pi_{\text{search}}^P$ is said to be computable if there is an algorithm $\mathcal{A}$ such that $\mathcal{A}(x) \in \mathrm{Sol}_P(x)$ when $\mathrm{Sol}_P(x) \neq \varnothing$ and $\mathcal{A}(x) = \bot$ otherwise.
\end{definition}

Here, the symbol $\bot$ is used to represent the fact that no solution exists for the given input instance. We observe that the definition allows any algorithm computing the problem to return a different solution on each execution. Optimization problems require an additional component: a \textit{cost function} $c : \Sigma^* \times \Sigma^* \to \R$ expressing the optimality of the solution for the given instance. We denote the set of optimal solutions as $\mathrm{Opt}_P(x) = \{y \in \mathrm{Sol}_P(x) \mid c(x,y) = \max_{z \in \mathrm{Sol}_P(x)} c(x,z)\}$. 


\begin{definition}
  The optimization problem of $P$ over $c$ is defined as the binary relationship $\Pi_{\text{opt}}^P = \{(x,y^*) \in \Sigma^* \times \Sigma^* \mid y \in \mathrm{Opt}_P(x)\}$. The problem $\Pi_{\text{opt}}^P$ is said to be computable if there is an algorithm $\mathcal{A}$ such that $\mathcal{A}(x) \in \mathrm{Opt}_P(x)$ when $\mathrm{Sol}_P(x) \neq \varnothing$ and $\mathcal{A}(x) = \bot$ otherwise.
\end{definition}

As previously stated, these three categories form an hierarchy of problems. This comes clear from their own definitions: any algorithm computing an optimization problem also computes a search problem and any algorithm computing a search problem can be adapted into one that computes a decision problem.

\section{Computational complexity}

In his seminal work, Turing \cite{turing} proved that some problems are \textit{undecidable}, meaning that there is no algorithm that can compute them exactly. Following his work, the pioneers of computer science started noticing that even thought many problems can be computed, the algorithms computing them would take too much resources, making them infeasible to process for large inputs. In particular, they focused on two main measures: \textit{time} and \textit{space}. 

\begin{definition}
  Let $\mathcal{A}$ be an algorithm and let $t, s \colon \N \to \R^+$ be two functions. We say that $\mathcal{A}$ \emph{runs in time} $t$ if on every input $x$ the algorithm halts after at most $t(|x|)$ steps and that $\mathcal{A}$ \emph{runs in space}
  $s$ if on every input $x$ it uses at most $s(|x|)$ cells memory cells.
\end{definition}

These two complexity measures are intrinsically related one to another and they are, usually, negatively correlated. Generally, if we allow our algorithm to use more space then the computation can be sped up by saving partial computations, while if we want to lower the amount of space needed then these partial computation have to be computed each time they're required.. Larger inputs require a larger amount of computational resources, making the values $t(n)$ and $s(n)$ proportional to the size $n$ of the input. For this reason, as the input size grows, we are interested in the asymptotic behavior of these measures.

To distinguish between efficiently solvable problems and intractable ones, we usually consider the class $\mathsf{P}$. This class is defined as the set of all decision problems solvable in polynomial time by an algorithm, meaning that there is an algorithm that computer the problem in time $O(n^c)$, for some $c > 0$. Similarly, we consider the class $\mathsf{FP}$ as the class of search problems solvable in polynomial time by an algorithm.

We observe that this definition allows the exponent $c$ to be as huge as possible. In real world situations, any algorithm with runtime larger than $O(n^3)$ is considered useless since it requires too much time even for smaller inputs. Nonetheless, this can be used at our advantage: if a problem doesn't lie in $\mathsf{P}$, it means that there is no algorithm for it even if we were to consider infinitely large values of $c$. Therefore, a decision problem $L$ is considered efficiently solvable when it lies in $\mathsf{P}$, while it is considered intractable when it doesn't. The same reasoning applies to the class $\mathsf{FP}$.

The aforementioned $\mathsf{P}$ vs. $\mathsf{NP}$ (or the $\mathsf{FP}$ vs. $\mathsf{FNP}$ question for search problems) question asks to settle if the class of efficiently solvable problems corresponds to the class of efficiently verifiable problems. Here, a \textit{verifier} for a problem $L$ is an algorithm that takes an additional input $w$, referred to as the \textit{witness}, and uses it to check if $x \in L$ holds or not. Usually, this witness is a string that describes a real solution of the problem for the given input. By definition, we have that $\mathsf{P} \subseteq \mathsf{NP}$ since if a problem is efficiently solvable then we can just ignore the given witness and solve the problem. Hence, the $\mathsf{P}$ vs. $\mathsf{NP}$ question asks to settle if this inclusion also holds in the converse direction, i.e.  $\mathsf{NP} \subseteq \mathsf{P}$. After almost 60 years of scientific literature studying this problem and its ramifications, researchers conjecture that the answer to this problem is negative.

\begin{conjecture}
  $\mathsf{P} \neq \mathsf{NP}$
\end{conjecture}

For our purposes, we'll assume this conjecture to be true. Another class of our interest is the class $\mathsf{coNP}$, defined as the set of all problems whose complement lies in $\mathsf{NP}$, i.e. $\mathsf{coNP} = \{L \subseteq \Sigma^* \mid \overline{L} \in \mathsf{NP}\}$. It's easy to see that problems that lie in $\mathsf{coNP}$ admit a verifier that use witnesses to discard invalid input instances: if $w$ is a witness for the membership of $x$ in $\overline{L}$ then $w$ is also a witness for the non-membership of $x$ in $L$. In other words, a problem is in $\mathsf{NP}$ if its correct instances can be efficiently verified, while a problem is is $\mathsf{coNP}$ if the same holds for incorrect instances. 

Again, its easy to see that $\mathsf{P} \subseteq \mathsf{coNP}$, but the converse is not known and it is actually a question equivalent to establishing that $\mathsf{P} \subseteq \mathsf{NP}$. This is due to the fact that if a problem is efficiently solvable then its complement is also efficiently solvable (we can just negate the output of the same algorithm). This same reasoning implies that if $\mathsf{P} = \mathsf{NP}$ then $\mathsf{NP} = \mathsf{coNP}$. Therefore, proving that $\mathsf{NP} \neq \mathsf{coNP}$ could be a way of establishing that $\mathsf{P} \neq \mathsf{NP}$. It is also conjectured that $\mathsf{NP} \neq \mathsf{coNP}$ since there evident asymmetries between the hardness of witnessing that something holds and that of witnessing something everywhere in mathematics and computer science.

\begin{conjecture}
  $\mathsf{NP} \neq \mathsf{coNP}$
\end{conjecture}

Finally, we introduce the concept of reductions between problems. Let $A$ and $B$ be two decision problems. We say that $A$ \textit{many-to-one reduces} to $B$, written as $A \leq_m B$ when there is a computable function $f : \Sigma^* \to \Sigma^*$ such that $x \in A$ if and only if $f(x) \in B$. The idea of problem reduction is simple: if a reducing function exists and the new problem can be solved then the original problem can also be solved. This is due to the fact that if an algorithm for the original problem has to simply compute the reduction and then execute the algorithm that solves the new problem.

It's easy to see that the relation $\leq_m$ forms a partial order over the power set $2^{\Sigma^*} = \{S \subseteq \Sigma^*\}$, corresponding to the set of all decision problems. When $A \leq_m B$ holds, we say that $B$ is \curlyquotes{at least as hard as} $A$ since a solving $B$ implies solving $A$. If the reduction is computable in polynomial time, we say that $A$ \textit{p-reduces} to $B$, written as $A \leq_p B$. In a two seminal papers, Cook and Levin \todo{add reference} independently showed that every problem that lies in $\mathsf{NP}$ is reducible to the \textit{satisfiability problem} $\mathrm{SAT} = \{\abk{\varphi} \mid \varphi \text{ a satisfiable CNF}\}$, where $\abk{\cdot}$ is the binary encoding. Problems with this property are referred to as $\mathsf{NP}$-hard and, under the assumption that $\mathsf{P} \neq \mathsf{NP}$, they cannot be solved in polynomial time. Therefore, showing the hardness of a problem comes as a tool of showing that it cannot be efficiently solved.

% be proved by combinatorial or algebraic means, and which \emph{imply} size
% lower bounds through size--width and size--degree trade-offs
% (Theorems~\ref{thm:size_width} and~\ref{thm:size_degree} below). This
% two-step strategy --- bound a simple measure, then transfer --- is the single
% most productive technique in the field.

% Resolution, introduced by Blake and developed by Davis, Putnam and
% Robinson~\cite{Robinson65}, is the simplest and best understood propositional

% \begin{definition}[Resolution] \label{def:resolution}
% The \emph{resolution rule} allows one to infer, from two clauses $C \vee x$ and
% $D \vee \neg x$, the clause $C \vee D$:
% \[
%   \frac{C \vee x \qquad D \vee \neg x}{C \vee D} .
% \]
% The clause $C \vee D$ is called the \emph{resolvent} of the premisses
% \emph{on the variable} $x$. Optionally one also allows the \emph{weakening}
% rule
% \[

% \]

% factor. A \emph{resolution refutation} of a CNF $F$ is a sequence of clauses
% ending in the empty clause $\square$, each of which is either a clause of $F$

% \end{definition}

% \begin{theorem}[Soundness and completeness] \label{thm:res_complete}
% A CNF $F$ is unsatisfiable if and only if it has a resolution refutation.

% Soundness is immediate: any assignment satisfying $C \vee x$ and
% $D \vee \neg x$ satisfies $C \vee D$, so from a satisfying assignment for $F$

% impossible. For completeness one argues by induction on the number of
% variables: if $F$ is unsatisfiable then so are the restrictions
% $F\!\restriction_{x=0}$ and $F\!\restriction_{x=1}$; refutations of the two
% restrictions can be reinstated to derive $x$ and $\neg x$ (or already
% $\square$), and one final resolution step finishes the derivation.
% \end{proof}

% Definition~\ref{def:measures}: length is the number of clauses, width is the

% polynomial factors.

% transfer.

% \begin{theorem}[Size--width, Ben-Sasson--Wigderson~\cite{BenSassonWigderson01}]
% \label{thm:size_width}

% \[
%   \LenOp_{\Res}(F) \ \ge\
%   \exp\left( \Omega\!\left(
%     \frac{\bigl( \wdt_{\Res}(F \vdash \square) - \wdt(F) \bigr)^{2}}{n}
%   \right) \right),
% \]
% and for tree-like resolution
% \[
%   \LenOp_{\Res^{*}}(F) \ \ge\

% \]

% \begin{theorem}[Haken~\cite{Haken85}] \label{thm:haken}
% Every resolution refutation of $\PHP^{n+1}_{n}$ has length

% \end{theorem}

% \begin{definition}[Tree-like resolution]
% A resolution refutation is \emph{tree-like} if its underlying dag is a tree,

% \end{definition}

% Tree-like resolution refutations of $F$ correspond exactly to the search trees

% \subsection{Frege proof systems} \label{sec:frege}

% Frege systems formalise the textbook notion of a Hilbert-style propositional
% calculus: one fixes a finite set of axiom schemes and rules and derives
% tautologies line by line. Lines are arbitrary propositional formulas, not
% merely clauses, which makes these systems considerably stronger than
% resolution.

% \begin{definition}[Frege rule]
% Fix a complete basis of connectives, say $\{\neg, \wedge, \vee, \to\}$. A
% \emph{Frege rule} is a $(k+1)$-tuple of propositional formulas
% $(A_{1}, \dots, A_{k}; B)$, written
% \[
%   \frac{A_{1} \quad \cdots \quad A_{k}}{B},
% \]
% in the variables $p_{1}, \dots, p_{\ell}$. The rule is \emph{sound} if every
% assignment satisfying all of $A_{1}, \dots, A_{k}$ also satisfies $B$. A rule
% with $k = 0$ is an \emph{axiom scheme}. An application of the rule is any
% substitution instance, obtained by replacing the $p_{i}$ uniformly by
% arbitrary formulas.
% \end{definition}

% \begin{definition}[Frege system] \label{def:frege}
% A \emph{Frege system} $\mathcal{F}$ is a finite set of sound Frege rules that
% is \emph{implicationally complete}: whenever a set of formulas $\Gamma$
% semantically implies $\varphi$, there is a derivation of $\varphi$ from
% $\Gamma$ using the rules of $\mathcal{F}$. An \emph{$\mathcal{F}$-proof} of
% $\varphi$ is a sequence $\varphi_{1}, \dots, \varphi_{m} = \varphi$ of formulas
% such that each $\varphi_{i}$ is obtained from earlier ones by an application of
% a rule of $\mathcal{F}$. The \emph{length} of the proof is $m$ and its
% \emph{size} is $\sum_{i} |\varphi_{i}|$.
% \end{definition}

% The classical example uses modus ponens, $\frac{A \quad A \to B}{B}$, together
% with a handful of axiom schemes. A remarkable robustness result says that the
% particular choice is irrelevant.

% \begin{theorem}[Reckhow~\cite{Reckhow76}] \label{thm:reckhow}
% Any two Frege systems over complete bases of connectives $p$-simulate each
% other.
% \end{theorem}

% Thus ``the'' Frege system is well defined up to $p$-equivalence, and one may
% speak of Frege proof size without ambiguity. Frege $p$-simulates resolution:
% a resolution refutation of $F$ is easily converted into a Frege proof of
% $\neg F$ with only polynomial overhead. In the other direction, no
% superpolynomial lower bound is known for Frege --- indeed, no
% superpolynomial lower bound is known even for Frege systems in which all lines
% are formulas of logarithmic depth. Proving such a bound is the central open
% problem of propositional proof complexity.

% \begin{definition}[Extended Frege]
% The \emph{extended Frege} system $\eF$ is obtained from a Frege system by
% adding the \emph{extension rule}: at any point of a proof one may introduce a
% line $q \leftrightarrow A$, where $A$ is any formula and $q$ is a fresh
% variable occurring neither in $A$, nor in the formula being proved, nor in any
% earlier line of the proof.
% \end{definition}

% Extension variables abbreviate subformulas, so that $\eF$ effectively reasons
% with \emph{circuits} rather than formulas. Frege corresponds in this sense to
% the circuit class $\mathrm{NC}^{1}$ and extended Frege to $\mathrm{P/poly}$;
% whether $\eF$ is strictly stronger than $\mathcal{F}$ is open, and is connected
% to the $\mathrm{NC}^{1}$ versus $\mathrm{P/poly}$ question. A further variant,
% \emph{substitution Frege}, adds a rule permitting the substitution of formulas
% into an already derived line, and is $p$-equivalent to $\eF$.

% Where lower bounds \emph{are} available is for the depth-restricted fragments.

% \begin{definition}[Bounded-depth Frege]
% Fix the basis $\{\neg, \wedge, \vee\}$ with unbounded fan-in $\wedge$ and
% $\vee$, negations pushed to the leaves. The \emph{depth} of a formula is the
% number of alternations of $\wedge$ and $\vee$ along a path from the root to a
% leaf. For $d \in \mathbb{N}$, the system $\mathcal{F}_{d}$ (\emph{depth-$d$
% Frege}) consists of the proofs of a fixed Frege system in which every line has
% depth at most $d$. The union of the $\mathcal{F}_{d}$ over constant $d$ is
% called $\mathrm{AC}^{0}$-Frege.
% \end{definition}

% \begin{theorem}[\cite{Ajtai94,KrajicekPudlakWoods95,PitassiBeameImpagliazzo93,Hastad21}]
% \label{thm:bounded_depth_php}
% For every $d \ge 2$, every depth-$d$ Frege refutation of $\PHP^{n+1}_{n}$ has
% size $2^{n^{\Omega(1/d)}}$.
% \end{theorem}

% The proofs proceed by a switching lemma tailored to the pigeonhole structure
% and mirror, on the proof-theoretic side, the circuit lower bounds for
% $\mathrm{AC}^{0}$. This parallel is systematic: progress on Frege lower bounds
% has repeatedly required, and been blocked by, the corresponding progress on
% circuit lower bounds. Bounded-depth Frege with counting gates modulo $p$
% ($\mathcal{F}_{d}(\oplus)$ and its relatives) is the current frontier.

% Cutting planes, introduced as a proof system by Cook, Coullard and

% \begin{definition}[Translation]
% A clause $C = \bigvee_{i \in P} x_{i} \vee \bigvee_{j \in N} \neg x_{j}$ is

% \[
%   \sum_{i \in P} x_{i} + \sum_{j \in N} (1 - x_{j}) \ \ge\ 1 ,
% \]
% that is, $\sum_{i \in P} x_{i} - \sum_{j \in N} x_{j} \ge 1 - |N|$. A CNF is

% \end{definition}

% \begin{definition}[Cutting planes] \label{def:cutting_planes}
% Lines are linear inequalities $\sum_{i=1}^{n} a_{i} x_{i} \ge b$ with
% $a_{i}, b \in \mathbb{Z}$. The \emph{axioms} are the translations of the
% clauses of $F$ together with the \emph{Boolean axioms}
% \[
%   x_{i} \ge 0, \qquad -x_{i} \ge -1 \qquad (i \in [n]).
% \]
% The rules are
% \[
%   \text{(addition)} \quad
%   \frac{\sum_{i} a_{i} x_{i} \ge b \qquad \sum_{i} a'_{i} x_{i} \ge b'}
%        {\sum_{i} (a_{i} + a'_{i}) x_{i} \ge b + b'},
%   \qquad
%   \text{(multiplication)} \quad
%   \frac{\sum_{i} a_{i} x_{i} \ge b}
%        {\sum_{i} c\,a_{i} x_{i} \ge c\,b}
%   \quad (c \in \mathbb{Z}_{>0}),
% \]
% \[
%   \text{(division)} \quad
%   \frac{\sum_{i} c\,a_{i} x_{i} \ge b}
%        {\sum_{i} a_{i} x_{i} \ge \lceil b/c \rceil}
%   \quad (c \in \mathbb{Z}_{>0}) .
% \]
% A \emph{$\CP$-refutation} of $F$ is a derivation of the contradictory
% inequality $0 \ge 1$. The \emph{size} of a refutation counts the bits needed to
% write down all coefficients; $\CP^{*}$ denotes the subsystem in which all
% coefficients are polynomially bounded (equivalently, written in unary).
% \end{definition}

% Only the division rule is specific to the integers: it is sound over
% $\{0,1\}^{n}$ (indeed over $\mathbb{Z}^{n}$) but not over $\mathbb{R}^{n}$, and
% it is exactly what gives cutting planes its power over mere linear-programming
% reasoning.

% \begin{theorem} \label{thm:cp_complete}
% Cutting planes is sound and complete for unsatisfiable CNFs, and $p$-simulates
% resolution.
% \end{theorem}

% The simulation is direct: a resolution step on $x$ is obtained by adding the
% two translated premisses, adding suitable Boolean axioms and dividing by $2$.
% The converse fails, and dramatically so: cutting planes has polynomial-size
% refutations of $\PHP^{n+1}_{n}$, which requires exponential size in resolution
% by Theorem~\ref{thm:haken}. Indeed, summing the pigeon axioms and the hole
% axioms and dividing yields a contradiction in $O(n^{2})$ steps, since counting
% arguments are native to the system.

% Lower bounds for cutting planes are known but harder to obtain, and were
% originally derived through interpolation.

% \begin{theorem}[Pudl\'ak~\cite{Pudlak97}] \label{thm:cp_lower}
% Cutting planes has feasible interpolation by monotone real circuits;
% consequently there are unsatisfiable CNFs of size $\mathrm{poly}(n)$ --- for

% $2^{n^{\Omega(1)}}$.
% \end{theorem}

% For $\CP^{*}$ an exponential separation from full $\CP$ is
% known~\cite{BonetPitassiRaz97,ImpagliazzoPitassiUrquhart94}, and the system
% sits strictly between resolution and $\CP$. Beyond cutting planes lie the
% semialgebraic systems --- Lov\'asz--Schrijver, Sherali--Adams and

% between the geometric and the algebraic worlds; we shall not need them here.

% \subsection{Algebraic proof systems} \label{sec:algebraic}
% % ---------------------------------------------------------------------

% Algebraic proof systems replace clauses by polynomials over a field and
% logical inference by ideal membership. The starting point is the observation
% that unsatisfiability of a CNF is the statement that a certain system of
% polynomial equations has no solution in $\{0,1\}^{n}$, which by Hilbert's
% Nullstellensatz is equivalent to the constant $1$ lying in the ideal generated
% by the system.

% \begin{definition}[Algebraic translation] \label{def:algebraic_translation}
% Fix a field $\mathbb{F}$. A clause
% $C = \bigvee_{i \in P} x_{i} \vee \bigvee_{j \in N} \neg x_{j}$ is translated
% into the polynomial equation
% \[
%   \prod_{i \in P} (1 - x_{i}) \prod_{j \in N} x_{j} \ =\ 0 ,
% \]
% which asserts that $C$ is not falsified. A CNF $F = C_{1} \wedge \dots \wedge
% C_{m}$ is translated into the family
% $\{ f_{1}, \dots, f_{m} \} \subseteq \mathbb{F}[x_{1}, \dots, x_{n}]$ of the
% corresponding polynomials, together with the \emph{Boolean axioms}
% \[
%   x_{i}^{2} - x_{i} \qquad (i \in [n]),
% \]
% which force every solution to be $0/1$-valued. Thus $F$ is unsatisfiable if and
% only if the system $\{f_{k} = 0\} \cup \{x_{i}^{2} - x_{i} = 0\}$ has no common
% root in $\overline{\mathbb{F}}$.
% \end{definition}

% \begin{definition}[Nullstellensatz~\cite{BeameImpagliazzoKrajicekPitassiPudlak94}]
% \label{def:nullstellensatz}
% A \emph{Nullstellensatz refutation} of $F$ over $\mathbb{F}$ is a family of
% polynomials $g_{1}, \dots, g_{m}, h_{1}, \dots, h_{n} \in
% \mathbb{F}[x_{1}, \dots, x_{n}]$ such that, as a polynomial identity,
% \[
%   \sum_{k=1}^{m} g_{k} f_{k}
%   \ +\ \sum_{i=1}^{n} h_{i} \,(x_{i}^{2} - x_{i})
%   \ =\ 1 .
% \]
% Its \emph{degree} is $\max_{k} \dg(g_{k} f_{k})$ and its \emph{size} is the
% total number of monomials occurring in the $g_{k}$ and $h_{i}$ when written out
% as sums of monomials.
% \end{definition}

% Nullstellensatz is a ``one-shot'' certificate: the entire refutation is a
% single algebraic identity. Its dynamic, line-based counterpart is the
% polynomial calculus, which is strictly stronger because it may build up the
% certificate in stages and thereby avoid writing large intermediate
% coefficients.

% \begin{definition}[Polynomial calculus~\cite{CleggEdmondsImpagliazzo96}]
% \label{def:pc}
% Lines are polynomials in $\mathbb{F}[x_{1}, \dots, x_{n}]$, understood as
% equations $p = 0$. The axioms are the polynomials $f_{1}, \dots, f_{m}$
% translating $F$ and the Boolean axioms $x_{i}^{2} - x_{i}$. The rules are
% \[
%   \text{(linear combination)} \quad
%   \frac{p \qquad q}{\alpha p + \beta q} \quad
%   (\alpha, \beta \in \mathbb{F}),
%   \qquad\qquad
%   \text{(multiplication)} \quad
%   \frac{p}{x_{i} \, p} \quad (i \in [n]).
% \]
% A \emph{$\PC$-refutation} of $F$ is a derivation of the constant polynomial
% $1$. Its \emph{degree} is the maximal degree of a line and its \emph{size} is
% the total number of monomials in all lines, each line being written in its
% expanded form.
% \end{definition}

% \begin{theorem}
% $\PC$ over any field is sound and complete for unsatisfiable CNFs: $F$ is
% unsatisfiable if and only if $1$ can be derived from its translation.
% \end{theorem}

% Completeness follows from the Nullstellensatz together with the fact that the
% Boolean axioms make the ideal radical; soundness holds because every rule
% preserves the property of vanishing on all common roots of the axioms.

% Degree is to the polynomial calculus what width is to resolution, and the
% analogue of Theorem~\ref{thm:size_width} holds.

% \begin{theorem}[Impagliazzo--Pudl\'ak--Sgall~\cite{ImpagliazzoPudlakSgall99}]
% \label{thm:size_degree}
% Let $F$ be an unsatisfiable CNF over $n$ variables in which every clause has
% width at most $d_{0}$, and let $d$ be the minimum degree of a $\PC$-refutation
% of $F$. Then every $\PC$-refutation of $F$ has size
% \[
%   \exp\left( \Omega\!\left( \frac{(d - d_{0})^{2}}{n} \right) \right) .
% \]
% \end{theorem}

% The same paper shows that the bound is essentially tight, and the degree
% lower bounds needed to apply it are obtained by algebraic adversary arguments,
% typically by exhibiting a linear operator $R$ on the space of low-degree
% polynomials that behaves like an ``evaluation'' consistent with all axioms but
% sending $1$ to something nonzero. Degree lower bounds are known for the
% pigeonhole principle, for random CNFs, for Tseitin formulas over expanders and
% for the counting principles, with the characteristic of $\mathbb{F}$ playing a
% decisive role: counting principles modulo $p$ are easy over fields of
% characteristic $p$ and hard otherwise.

% One weakness of $\PC$ as defined above is that the translation of a wide clause
% is a single monomial of high degree, but the translation of a \emph{negated}
% literal costs a factor of two in the number of monomials, so that a clause with
% $k$ positive literals expands to $2^{k}$ monomials. As a result $\PC$ does not
% simulate resolution with respect to size. The standard remedy is to add formal
% variables for negated literals.

% \begin{definition}[Polynomial calculus with resolution,
% $\PCR$~\cite{AlekhnovichBenSassonRazborovWigderson02}]
% \label{def:pcr}
% $\PCR$ is the system obtained from $\PC$ by adding, for each variable $x_{i}$,
% a new formal variable $\bar{x}_{i}$ together with the axioms
% \[
%   x_{i} + \bar{x}_{i} - 1 \qquad (i \in [n]),
% \]
% and by translating a clause
% $\bigvee_{i \in P} x_{i} \vee \bigvee_{j \in N} \neg x_{j}$ into the single
% monomial $\prod_{i \in P} \bar{x}_{i} \prod_{j \in N} x_{j}$. Degree and size
% are defined as before, over the extended variable set.
% \end{definition}

% \begin{proposition} \label{prop:pcr_simulates_res}
% $\PCR$ $p$-simulates resolution, and $\PC$ and $\PCR$ have the same minimum
% refutation degree up to a constant factor. Moreover, $\PCR$ over any field is
% exponentially separated from resolution.
% \end{proposition}

% Thus $\PCR$ is a common strengthening of resolution and of $\PC$ that retains
% the algebraic notion of degree, and it is the algebraic system of choice when
% size is the measure of interest. Finally, algebraic systems are distinguished
% by a positive algorithmic result, which has no counterpart for Frege-style
% systems.

% \begin{theorem}[Clegg--Edmonds--Impagliazzo~\cite{CleggEdmondsImpagliazzo96}]
% \label{thm:groebner}
% There is an algorithm that, given an unsatisfiable CNF $F$ over $n$ variables

% time $n^{O(d)}$.
% \end{theorem}

% The algorithm is a form of Gr\"obner basis computation: it closes the set of
% derived polynomials of degree at most $d$ under the two rules, which amounts to

% Theorem~\ref{thm:size_degree}, it shows that $\PC$ is quasi-automatable in a
% weak sense for formulas of small refutation degree, and it is one of the
% reasons why algebraic systems are unusually well-behaved from an algorithmic
% standpoint.

% \section{Prover--Delayer game} \label{sec:prover_delayer}
% % =====================================================================

% Lower bound arguments for tree-like systems can be recast as two-player games,
% in which one player tries to falsify a clause quickly and the other tries to
% delay this for as long as possible. The resulting technique, due to Pudl\'ak
% and Impagliazzo~\cite{PudlakImpagliazzo00}, replaces the combinatorial analysis
% of a proof by the design of a single adversary strategy, and is often much
% easier to carry out.

% \begin{definition}[Prover--Delayer game] \label{def:pd_game}
% Let $F$ be an unsatisfiable CNF over the variables $V$. The
% \emph{Prover--Delayer game} on $F$ is played between two players, \emph{Prover}
% and \emph{Delayer}, who together build a partial assignment $\alpha$, initially
% empty. In each round:
% \begin{enumerate}
%   \item Prover selects a variable $x \in V$ not yet assigned by $\alpha$;
%   \item Delayer either answers $0$ or $1$, or defers the choice by replying
%         \emph{``you choose''}; in the latter case Prover selects the value
%         $b \in \{0,1\}$ himself and Delayer \emph{scores one point};
%   \item the chosen value is added to $\alpha$.
% \end{enumerate}
% The game ends as soon as $\alpha$ falsifies some clause of $F$. Delayer's aim
% is to maximise the number of points scored, Prover's to minimise it. We denote
% by $\mathrm{val}(F)$ the value of the game, i.e.\ the maximum $k$ such that
% Delayer has a strategy scoring at least $k$ points against every Prover.
% \end{definition}

% The intuition is that Prover is a DPLL algorithm querying variables in order to
% reach a contradiction, while Delayer is an adversary maintaining the illusion
% that $F$ is satisfiable. A point is scored exactly when Delayer has no
% preference, i.e.\ when both extensions of the current assignment still look
% consistent, and this is precisely the situation in which Prover's search tree
% must branch in an essential way.

% \begin{theorem}[Pudl\'ak--Impagliazzo~\cite{PudlakImpagliazzo00}]
% \label{thm:pd_lower}
% Let $F$ be an unsatisfiable CNF. If Delayer has a strategy scoring at least $k$
% points in the Prover--Delayer game on $F$, then every tree-like resolution
% refutation of $F$ has size at least $2^{k}$. In symbols,
% \[
%   \size_{\Res^{*}}(F) \ \ge\ 2^{\,\mathrm{val}(F)} .
% \]
% \end{theorem}

% \begin{proof}
% Let $T$ be a tree-like resolution refutation of $F$ of size $S$; read from the
% root $\square$ upwards, $T$ is a binary decision tree whose internal nodes are
% labelled by variables and whose leaves are labelled by clauses of $F$. We
% describe a Prover strategy that scores at most $\log S$ points against every
% Delayer.

% Prover maintains a node $v$ of $T$, initially the root, and the invariant that
% the current partial assignment $\alpha$ is the one determined by the path from
% the root to $v$. At node $v$, Prover queries the variable $x$ labelling $v$. If
% Delayer answers $b \in \{0,1\}$, Prover moves to the child of $v$ corresponding
% to $b$. If Delayer replies ``you choose'', Prover moves to the child $u$ of $v$
% whose subtree $T_{u}$ has the smaller number of nodes and sets $x$ accordingly;
% since the two subtrees partition the remaining nodes, in this case
% \[
%   |T_{u}| \ \le\ \tfrac{1}{2}\,|T_{v}| .
% \]
% When a leaf is reached, the assignment along the path falsifies the clause
% labelling it, so the game ends. The size of the current subtree starts at $S$
% and is at least $1$ at the end, and it is at least halved at every point
% scored; hence Delayer scores at most $\log S$ points. If Delayer can guarantee
% $k$ points, then $k \le \log S$, i.e.\ $S \ge 2^{k}$.
% \end{proof}

% The argument is genuinely a lower bound method: to prove that $F$ is hard for
% tree-like resolution it suffices to design a Delayer strategy, which is a local
% and often transparent combinatorial task. For the pigeonhole principle, for
% instance, Delayer answers $0$ to a query $x_{i,j}$ unless doing so would leave
% pigeon $i$ with no free hole, and replies ``you choose'' whenever fewer than
% half of the holes are still free for the queried pigeon; a counting argument
% shows that $\Omega(n \log n)$ points are scored, whence a $2^{\Omega(n\log n)}$
% lower bound for tree-like resolution refutations of $\PHP^{n+1}_{n}$.

% Theorem~\ref{thm:pd_lower} has a converse, so the game does not merely give
% lower bounds but characterises the measure.

% \begin{proposition} \label{prop:pd_converse}
% If every Delayer strategy scores at most $k$ points against some fixed Prover
% strategy, then $F$ has a tree-like resolution refutation of size
% $2^{O(k)}\cdot \mathrm{poly}(|F|)$.
% \end{proposition}

% The symmetric game of Definition~\ref{def:pd_game} is, however, not tight: the
% $2^{k}$ bound of Theorem~\ref{thm:pd_lower} loses a factor whenever the two
% answers to a query are not equally plausible, because Delayer is paid the same
% point for a query on which he is nearly certain as for one on which he is
% indifferent. Beyersdorff, Galesi and Lauria~\cite{BeyersdorffGalesiLauria13}
% removed this loss by letting Delayer price the two answers.

% \begin{definition}[Asymmetric Prover--Delayer game] \label{def:asym_pd_game}
% The game is played as in Definition~\ref{def:pd_game}, except that when Prover
% queries a variable $x$, Delayer either answers $0$ or $1$ outright, scoring
% nothing, or specifies two positive rationals $c_{0}, c_{1}$ with
% \[
%   \frac{1}{c_{0}} + \frac{1}{c_{1}} \ =\ 1 ,
% \]
% whereupon Prover chooses the value $b \in \{0,1\}$ and Delayer scores
% $\log c_{b}$ points.
% \end{definition}

% Choosing $c_{0} = c_{1} = 2$ recovers the symmetric game, in which each
% deferred query is worth exactly one point; choosing $c_{0}$ close to $1$ and
% $c_{1}$ large expresses the belief that the value $0$ is much more likely, and
% is rewarded accordingly if Prover chooses $1$ anyway.

% \begin{theorem}[\cite{BeyersdorffGalesiLauria13}] \label{thm:asym_pd}
% Let $F$ be an unsatisfiable CNF. If Delayer has a strategy scoring at least $k$
% points in the asymmetric Prover--Delayer game on $F$, then every tree-like
% resolution refutation of $F$ has size at least $2^{k}$. Conversely, if $F$ has
% a tree-like resolution refutation of size $S$, then Prover has a strategy
% keeping Delayer's score below $\log S$. Hence the value of the asymmetric game
% determines $\log \size_{\Res^{*}}(F)$ exactly.
% \end{theorem}

% The proof of the lower bound direction refines the one above: instead of
% halving the current subtree, Prover chooses the child $u$ minimising the ratio
% $|T_{u}| \cdot c_{b}$, and an averaging argument based on the constraint
% $1/c_{0} + 1/c_{1} = 1$ shows that the subtree shrinks by a factor of at least
% $c_{b}$ whenever $\log c_{b}$ points are paid; the product of the factors along
% the play is then at most $S$.

% Because the characterisation is exact, the asymmetric game can also be used to
