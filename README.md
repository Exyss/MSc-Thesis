## Abstract

Modern SAT solvers decide formulas with millions of variables and, whenever they report that a formula is unsatisfiable, they implicitly construct refutations of them in some proof system. Whether such proofs can always be found efficiently is the question of automatability. A proof system $Q$ is said to be automatable if a proof of any tautology can be found in time polynomial with respect to the size of its shortest $Q$-proof. Under standard cryptographic assumptions, strong systems such as Frege are not automatable. In recent years, a line of work started by Atserias and Müller extended this by showing that Resolution and many weak systems are not automatable unless $\mathsf{P} = \mathsf{NP}$. Their key tool comes from meta-complexity: the formula $\mathrm{Ref}_s(\varphi)$, stating that $\varphi$ has a Resolution refutation of size at most $s$, is easy to refute when $\varphi$ is satisfiable and exponentially hard to refute otherwise. Arteche, Atserias, de Rezende and Khaniki recently turned this argument around and introduced the Proof Analysis Problem: given a proof of a Resolution lower bound for $\varphi$, decide whether $\varphi$ is satisfiable. A proof system for which this is possible in polynomial time is called analyzable.

This thesis presents these results in a self-contained way to then extend them by investigating analyzability of proof systems above Resolution. In particular, we prove that Polynomial Calculus with Resolution (PCR) is analyzable, hence so are Nullstellensatz and Polynomial Calculus, and obtain a new proof that automating PCR is $\mathsf{NP}$-hard. This is the first analyzability result for a system not below Resolution. We also compare analyzability with feasible interpolation, another property closely related with automatability. We show that proving that feasible interpolation implies analyzability would show that Resolution is not weakly automatable unless $\mathsf{P} = \mathsf{NP}$. Conversely, for every disjoint $\mathsf{NP}$-pair we construct an analyzable proof system that has feasible interpolation only if the pair is polynomial-time separable. This last result shows that, under standard assumptions, analyzability does not imply feasible interpolation.
